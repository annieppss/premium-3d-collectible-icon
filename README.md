# Premium 3D Collectible Icon

Create cute, premium 3D collectible icons with polished PVC, resin, and acrylic materials.

![Premium 3D collectible icon set](assets/pvc-3d-collectible-icon-set.png)

## Use

```text
$premium-3d-collectible-icon 튜브에 탄 귀여운 강아지
```

The skill automatically applies a bright summer palette, soft studio lighting, a simple bold silhouette, and creature/non-living-object rules.
